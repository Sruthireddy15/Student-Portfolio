# Portfolio Builder

A simple student portfolio website created to showcase personal information, skills, education, hobbies, and projects.

## About the Project

This project is a basic portfolio website developed using HTML and CSS. It is designed to present a student's profile in a simple and organized way.

## Features

- About Me section
- Profile photo
- Hobbies section
- Skills section
- Education details
- Projects section
- Contact section
- Create Portfolio page

## Technologies Used

- HTML
- CSS
